## ボード画面(概要)

```
┌───────────────────────────────────────────────┐
│                  タスク管理                     │
├───────────────┬───────────────┬───────────────┤
│    未着手      │     着手       │     完了       │
├───────────────┼───────────────┼───────────────┤
│ [カード]       │ [カード]       │ [カード]       │
│ [カード]       │               │               │
│               │               │               │
│ [+ カードを追加]│ [+ カードを追加]│ [+ カードを追加]│
└───────────────┴───────────────┴───────────────┘
```

- 画面上部にアプリタイトルを表示する
- 「未着手」「着手」「完了」の3カラムを横に並べて表示する
- 各カラムの末尾に「+ カードを追加」ボタンを表示する
