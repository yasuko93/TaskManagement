# 設計スタック

[← 要件定義書に戻る](requirements.md)

本アプリの実装に用いる技術スタックを定める。

## 決定事項

| 項目 | 内容 |
|---|---|
| DB | SQLite を想定 |
| 通信方式 | フロントエンドはバックエンドが提供する REST API 経由でデータを取得・更新する |
| 構成 | フロントエンドとバックエンドを分離した一般的なWebアプリケーション構成([データベース設計](database-design.md)参照) |
| 動作環境 | 最新版の主要ブラウザ(Chrome / Edge など) |
| 文字コード | UTF-8 |

## 未決定事項

- フロントエンドの言語・フレームワーク
- バックエンドの言語・フレームワーク
- 開発・実行環境(ローカル起動方法、ポート構成など)

技術選定後、本ドキュメントを更新する。
